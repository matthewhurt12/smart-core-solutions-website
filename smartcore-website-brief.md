# SmartCore Solutions Website Build Brief

## For: Cursor AI / Web Development

---

## PROJECT OVERVIEW

Build a modern, professional single-page website (or simple multi-page) for SmartCore Solutions, a GPS fleet tracking and IoT monitoring company based in Georgia. The site will be hosted on GitHub Pages as static HTML/CSS/JS.

**Owner:** Matthew, 24-year-old entrepreneur
**Business Age:** 2+ years
**Core Offering:** GPS fleet tracking at $25/month per vehicle, plus building monitoring and vape detection

---

## BRAND IDENTITY

### The Vibe
- **Young tech entrepreneur** — not corporate, not mom-and-pop
- **Smart, technical, innovative** — cool technology, integrations, IoT
- **Transparent and personal** — you call Matthew directly
- **Confident but approachable** — knows what he's doing, easy to work with

### What We're NOT
- Generic "solutions provider" corporate speak
- Local handyman/contractor vibes
- Enterprise tech company pretending to have 500 employees
- Overly casual or unprofessional

### Visual Direction
- Dark/modern tech aesthetic (think: dark grays, blacks, with accent color)
- Clean typography — bold headlines, readable body text
- Lots of whitespace
- Subtle motion/hover effects (nothing cheesy)
- Real photos of Matthew and installations (placeholders for now)
- Device mockups showing dashboard/app interface

### Suggested Colors
- Primary: Deep navy or charcoal (#1a1a2e or #0f0f1a)
- Accent: Electric blue, teal, or green (#00d4aa, #3b82f6, or #10b981)
- Text: White/light gray on dark backgrounds
- Cards/sections: Slightly lighter dark (#252538 or similar)

### Typography Suggestions
- Headlines: Inter, Outfit, or Space Grotesk (bold, modern)
- Body: Inter, DM Sans, or similar (clean, readable)

## TECHNICAL REQUIREMENTS

### Stack
- **HTML5 / CSS3 / Vanilla JS** (or Tailwind CSS if preferred)
- **Static site** — no backend required
- **Hosted on GitHub Pages**

### Performance
- Fast loading (optimize images, minimal dependencies)
- Mobile-first responsive design
- Smooth scroll between sections
- Lazy load images

### Sections
- Fixed/sticky navigation with smooth scroll to sections
- Clear visual hierarchy between sections
- Alternating background colors/shades for section separation

### Interactive Elements
- Hover effects on buttons and cards
- Smooth scroll navigation
- Mobile hamburger menu
- Contact form (can use Formspree, Netlify Forms, or similar for handling)

### SEO Basics
- Proper meta tags (title, description)
- Open Graph tags for social sharing
- Semantic HTML structure
- Alt text on images

## COPY TONE REFERENCE

**DO:**
- Write like a smart person talking to another smart person
- Be direct and clear
- Use "I" not "we" (solo founder)
- State facts confidently
- Keep it concise

**DON'T:**
- Use corporate buzzwords ("synergy," "leverage," "solutions")
- Oversell or exaggerate
- Use passive voice
- Include unnecessary filler text
- Make it sound like a big company
